# Creative catalog expansion — 2026-10-09

Public product information was checked on 2026-10-09 (Asia/Shanghai). This is editorial discovery data, not a firsthand review. No popularity counts, rankings, invented founding dates, or generation-quality guarantees were added. No launchDate/launchSource is assigned in this batch: exact recent PH daily records were not established for all eight products.

## Coverage

| Category | Newly included external products |
| --- | --- |
| Image generation | FLORA, KREV |
| Video creation | FLORA, KREV (Pexo already exists) |
| Audio tools | Aqua Voice, Willow Voice |
| 3D generation | Sloyd, Hyper3D Rodin |
| Virtual companions | Mochi Desktop Pet, AIRI |

Audio tools also have supported writing-assistance uses. Mochi has optional file tidying, so productivity is also appropriate. AIRI is presented as configurable virtual-character software; neither companionship entry is promoted as an adult or romantic service.

## Verification notes and limits

- FLORA: [official site](https://flora.ai/) and [PH product](https://www.producthunt.com/products/flora-3). Former florafauna.ai redirects to flora.ai. Confirmed canvas, image/video workflows, reusable techniques. Do not describe supported providers or exact model counts as fixed.
- KREV: [official site](https://www.krev.ai/) and [PH product](https://www.producthunt.com/products/krev). Current site has expanded beyond the older creative launch into ecommerce workflows. Entry concentrates on official product-photo and video creative capabilities, not promised conversion or savings.
- Aqua Voice: [official site](https://aquavoice.com/), [download](https://aquavoice.com/download), [PH product](https://www.producthunt.com/products/aqua). Download page explicitly offers Mac and Windows. Mobile references exist elsewhere, but catalog platforms are limited to the verified desktop downloads. No typing-speed or accuracy claim is adopted.
- Willow Voice: [official site](https://willowvoice.com/), [PH product](https://www.producthunt.com/products/willow-voice). Confirmed Mac, Windows, iPhone, dictation formatting and Scribe. The official marketing image includes a performance claim; alt text identifies this as maker promotional wording, not NavoKit testing.
- Sloyd: [official site](https://www.sloyd.ai/), [official documentation](https://sloyd.gitbook.io/documentation). Text/image generation, templates, refinement/export are supported. No PH product record could be reliably verified, so none is invented or linked. Included as a focused 3D workflow product; not represented as a newly founded company.
- Hyper3D Rodin: [official site](https://hyper3d.ai/), [Blender add-on docs](https://docs.deemos.dev/addon), [PH maker/product page](https://www.producthunt.com/products/chatavatar-2). The PH page is titled DeemosTech and includes the older Rodin Gen-1 launch; this is historical provenance, not a current launch date. Current functionality comes from Hyper3D. Blender/Chrome version requirements apply only to that integration.
- Mochi Desktop Pet: [creator page](https://nickmorefun.itch.io/mochi), [PH product](https://www.producthunt.com/products/mochi-6). Verified macOS 13+, optional folder moves with undo, own-key AI comments and a paid life-sim extension. Maker reports the app is not notarized; included in the requirements. No installation or security setting was changed. Do not confuse with the unrelated Mochi flashcard product.
- AIRI: [official overview](https://airi.moeru.ai/docs/en/docs/overview/), [official release](https://github.com/moeru-ai/airi/releases/latest), [PH product](https://www.producthunt.com/products/airi). Confirmed open source, web/desktop, Live2D/VRM, voice/text. Provider and speech setup can have costs, so the catalog does not imply that every hosted operation is free.
